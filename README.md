# PMEX Supez Dex

Pixel-style infographic viewer for **Pokémon Masters EX** datamine: every sync pair with moves, passives, stats and a pixel-art Sync Grid; monthly scout banners with a Gantt timeline; and Pasio Gym Battle circuits (rules per circuit, boss HP scaling, rewards). Five themes: Night, Pokédex, Game Boy, Master Ball, Sakura.

## Layout

```
datamine/   local clone of github.com/absolutelypm/pokemas-datamine (2.71/, 2.72/, …) — gitignored, never committed
site/       the static website (deploy this folder)
  data/     GENERATED by the build: data.js (summary) + pairs/<id>.js (details)
  assets/   GENERATED: pixel sprites (Pokémon Showdown) and item icons (PokéAPI)
scripts/    build + data tools (Node ≥ 18, no npm dependencies)
config/     hand-verified tables: outfit-sprites.json, custom-trainer-sprites.json + trainer-sprites/
docs/       how the data is parsed and how to update (Vietnamese)
.cache/     raw PoMaTools crawl + outfit review sheets (gitignored)
```

## Setup

```bash
git clone <this repo> && cd <repo>
npm run setup-data      # clones the dataminer's repo into ./datamine (gitignored)
```

## Monthly update

```bash
npm run update-data     # git pull inside ./datamine
npm run crawl           # optional: refresh older pairs from PoMaTools
npm run build           # regenerate site/data + fetch any new sprites
npm run serve           # http://localhost:8765
```

Then commit `site/data`, `site/assets` (and `config/` if you verified new outfits). `datamine/` is never committed.
Details and checks: [docs/update-workflow.md](docs/update-workflow.md). In Claude Code, `/update-datamine-web` runs the same procedure.
